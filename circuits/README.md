# EE305 Module 1 회로 실험

2026년 봄 전자설계실험에서 회로를 구성하고 입력 조건을 바꾸며 시간·주파수 영역의 응답을 측정했습니다.

## 측정 내용

- 오실로스코프의 AC/DC coupling과 trigger 설정
- RC 과도응답과 RC/RL 주파수 응답
- RLC 공진 주파수와 Q-factor
- OP AMP 저역·고역 통과 필터
- LM386 오디오 증폭과 필터

[실험 보고서](Module_1_Post_Lab_Report.pdf)에 회로 구성, 측정표, 파형, 계산과 해석을 담았습니다. RLC 공진 주파수는 계산값 3,395 Hz와 측정값 3,295 Hz를 비교했으며, RC/RL 회로의 주파수별 응답도 분석했습니다.
