# EE305 Module 1 회로 실험

2026년 봄 전자설계 실험의 Module 1에서 오실로스코프 AC/DC coupling·trigger, RC 과도응답, RC/RL 주파수 응답, RLC 공진·Q-factor, OP AMP LPF/HPF, LM386 오디오 증폭·필터를 측정·분석했습니다.

회로 구성과 측정 조건을 바꾸며 시간·주파수 영역의 응답을 비교하고 개인 Post-Lab Report로 정리한 실험입니다. 별도 소프트웨어 제품이나 이번에 재측정한 결과가 아닙니다. 강의자료나 과제지 전체를 복제하지 않고 본인 실험 내용을 요약합니다.

[개인 실험 보고서 원본](Module_1_Post_Lab_Report.pdf)에 측정표·파형·계산과 해석이 있습니다. RLC 공진의 계산 3,395 Hz와 당시 측정 3,295 Hz, RC/RL 응답 비교 등은 당시 보고서의 기록입니다. 이번 정리에서 새로 측정한 값이 아닙니다.
